# Android companion

This Expo / React Native app includes explicit camera and speech-recognition permission flows, a front-camera preview, example voice commands, and explicit Android intent-based launching of supported installed packages. To run: `npm run dev:mobile`. Install an Android development build for native speech recognition and the included custom accessibility service; Expo Go does not install this service. Generate it with `npm run prebuild`, then `npm run android` with Android Studio and the Android SDK installed.

The prebuild config plugin adds an Android accessibility service and a React Native bridge for the system `Back` and scroll actions. Users enable the service themselves under Android Settings → Accessibility → Installed apps → Brainbight gesture controls. Android requires the user to authorize it. The front-camera preview is foreground-only. Tap **Analyze this frame** to process one frame through a configured, locally reachable Python service and trigger the recognized command. Voice transcription uses Android's system speech-recognition provider, and opening supported apps uses explicit Android package intents.

For local gesture-service inference, install the Python requirements, obtain a compatible MediaPipe Tasks hand-landmarker `.task` model under its terms, and set `BRAINBIGHT_HAND_MODEL` to that file. Set `EXPO_PUBLIC_GESTURE_API_URL` to the Python service's base URL before starting the mobile development build. On an Android emulator, use `http://10.0.2.2:8000`; on a physical device, use your computer's reachable LAN address. Camera frames are sent to this local endpoint only after a user taps the analysis button. Snapshot-based inference is a development prototype, not continuous background gesture control.
